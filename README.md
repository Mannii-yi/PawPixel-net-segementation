# PawPixel-Net: Uncertainty-Aware Semantic Segmentation with Adaptive Attention U-Nets and Test-Time Augmented Ensemble Inference

A semantic segmentation pipeline built on the Oxford-IIIT Pet dataset, comparing a baseline U-Net against an enhanced Attention U-Net — with test-time augmentation (TTA) for both accuracy gains and pixel-wise uncertainty estimation.

---

## Overview

This project trains and evaluates two segmentation architectures to isolate pet (foreground) pixels from background in natural images:

1. **Baseline U-Net** — ResNet34 encoder, standard decoder, trained with a combined Dice + BCE loss.
2. **Enhanced Attention U-Net** — ResNet34 encoder with **scSE (concurrent spatial and channel squeeze-excitation) attention** in the decoder, trained with **Focal Tversky loss** to better handle boundary and small-region imbalance.

Both models are evaluated with **test-time augmentation** (horizontal/vertical flips, 90°/180°/270° rotations, brightness jitter), which is also repurposed to generate **pixel-wise uncertainty maps** — showing where the model is confident versus where predictions are unstable across augmented views (typically object boundaries and fine detail like fur/ear edges).

---

## Why U-Net

U-Net's encoder-decoder structure with skip connections is well suited to segmentation because it solves a core tension in the task: the encoder progressively downsamples the image to build strong semantic understanding of *what* is in the image, while losing precise spatial detail along the way. The decoder upsamples back to full resolution to recover *where* things are — and the skip connections feed high-resolution features from each encoder stage directly into the corresponding decoder stage, so fine boundary detail isn't lost to the bottleneck. This is what allows pixel-accurate masks rather than coarse blobs.

The **Attention U-Net** variant adds scSE blocks in the decoder, which let the network learn to weight *which channels* and *which spatial regions* matter most before merging skip-connection features — helping suppress irrelevant background texture and sharpen focus on the actual object.

## Results

| Model | Encoder | Loss Function | Val IoU | Val Dice |
|---|---|---|---|---|
| Baseline U-Net | ResNet34 | Dice + BCE | **0.8929** | **0.9434** |
| Attention U-Net | ResNet34 (scSE) | Focal Tversky | 0.8818 | 0.9372 |

Both models converge to strong, comparable performance on this dataset. The baseline slightly edges out on raw IoU/Dice, while the attention variant's Focal Tversky loss was tuned to prioritize recall on foreground pixels — a trade-off worth making in domains where missing part of the object (false negatives) is costlier than over-segmenting slightly (false positives), such as medical lesion delineation.

### Reading the uncertainty maps

The uncertainty heatmap is generated by running each image through 8 augmented views (flips, rotations, brightness shift) and computing the **pixel-wise variance** across the resulting predictions. Brighter regions indicate views disagreeing with each other — in practice, this consistently highlights object **boundaries and fine structures** (ear edges, fur wisps) rather than flat interior or background regions, which matches the intuitive expectation: the model is confident about "this is clearly pet" or "this is clearly background," but genuinely uncertain about the exact boundary pixel.

## Method Details

- **Dataset:** Oxford-IIIT Pet (trainval/test split), binary foreground/background masks derived from trimap annotations.
- **Augmentation (training):** resize, horizontal flip, brightness/contrast jitter, shift-scale-rotate.
- **Loss functions:**
  - *Dice + BCE* — stable, standard combination for balanced foreground/background ratios.
  - *Focal Tversky* — asymmetric penalty (β > α) on false negatives, with a focal term to emphasize hard examples; better suited to imbalanced or boundary-heavy segmentation tasks.
- **Optimizer:** AdamW with cosine annealing LR schedule, mixed-precision (AMP) training.
- **Metrics:** IoU (Jaccard Index) and Dice coefficient, tracked per epoch on a held-out validation split.
- **Inference-time enhancements:** flip-averaged TTA for prediction accuracy; 8-view augmented variance for uncertainty estimation.

---

## Key Insights

- **Loss function choice materially changes model behavior**, not just convergence speed — Focal Tversky's asymmetric penalty visibly shifted predictions toward better boundary recall at a small cost to overall IoU, illustrating that "best loss" depends on what error type is more costly in the target application.
- **Attention doesn't automatically mean better metrics** — the scSE attention variant didn't outperform the plain baseline on this particular dataset/size, a useful reminder that added architectural complexity should be validated empirically, not assumed beneficial.
- **TTA is a low-cost, high-value addition** — reusing the same augmentation infrastructure for both accuracy (flip-averaging) and uncertainty estimation (variance across views) delivered two capabilities from one mechanism, without needing dropout layers or a second model.
- **Uncertainty maps concentrate meaningfully at object boundaries**, not randomly across the image — this is a strong qualitative signal that the variance-based estimate is capturing genuine model ambiguity rather than noise.

## Engineering Notes

This project was built under significant environment constraints, which shaped some of the practical decisions:

- Local development hit persistent DNS/network resolution failures when downloading the dataset via `torchvision`, which did not resolve through standard troubleshooting (network switch, DNS changes) in the available time.
- The project was migrated to **Google Colab** to get a reliable network path and free GPU access, which also meant restructuring the codebase to work with Colab's ephemeral filesystem (session resets periodically clear installed packages and written files, requiring re-execution of setup cells).
- Initial uncertainty estimation used MC-Dropout, but the encoder/decoder architecture had insufficient dropout layers to produce meaningful variance — this was replaced with a **TTA-based variance estimate**, which turned out to be both more reliable and more interpretable.

These constraints are noted for transparency rather than as excuses — the final pipeline is fully reproducible end-to-end from a clean Colab runtime.
